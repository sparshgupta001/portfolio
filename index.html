framework

How I Design

A grounded, human-centered framework I practice and demonstrate across each project below — transforming ambiguous problems into clear, production-ready experiences.

01 Discover

Understand

Start with the person and their daily context. Listen to how they navigate current workarounds and identify what causes friction, fatigue, or distrust before sketching pixels.

→ Applied in Doppelgänger Research
User Inquiries Mental Models Empathy Mapping
02 Synthesize

Define

Distill raw observations into sharp problem statements, explicit constraints, and measurable design criteria. Identify what must be obvious in the first 5 seconds.

→ Applied in Doppelgänger Alarm Fatigue
Problem Framing Information Hierarchy Success Metrics
03 Diverge

Explore

Explore multiple divergent interaction flows and low-fidelity wireframes. Compare architectural alternatives before converging on the model with the lowest cognitive friction.

→ Applied in DevEx Wireframe Trade-offs
User Flows Low-Fi Wireframes Trade-Off Analysis
04 Build

Prototype

Bring ideas into reality with living high-fidelity UI and code prototypes. Test realistic edge cases, responsive adaptations, and micro-interactions so the solution can be felt.

→ Applied in Provenance 3-Tier Prototype
Interactive Prototyping Component Design Code Feasibility
05 Learn

Validate

Put prototypes in front of real users. Watch where people hesitate, listen to their immediate confusion, and treat unexpected behaviors as the most valuable feedback.

→ Applied in HackOasis V3 (2nd of 75+)
Usability Testing Task Success Rate Qualitative Notes
06 Refine

Iterate

Refine visual polish, accessibility (contrast, keyboard focus, screen readers), and state handling based on evidence. Prepare systematic handoffs for engineering execution.

→ Applied in Provenance 3-Tier IA Refinement
Accessibility Tuning Micro-Interactions Design Handoff

Privacy & Security UX Chrome Extension JavaScript & Chrome APIs

Doppelgänger 🕵️

Identifying web privacy risks without triggering alarm fatigue

A Chrome extension that identifies potential privacy and security risks in web interactions. Built with plain-language risk levels, one clear action per warning, calm color coding with non-color cues (icon+label), and progressive disclosure to keep non-technical users informed without alarm fatigue.

Core UX Challenge

Showing risk to non-technical people without causing alarm fatigue.

Deliverables

Chrome extension, plain-language risk hierarchy, and comprehensive project report.
