How I Design

A grounded, human-centered framework I practice and demonstrate across each project below — transforming ambiguous problems into clear, production-ready experiences.

01 Discover

Understand

Start with the person and their daily context. Listen to how they navigate current workarounds and identify what causes friction, fatigue, or distrust before sketching pixels.

→ Applied in Doppelgänger Research
User Inquiries Mental Models Empathy Mapping
02 Synthesize

Define

Distill raw observations into sharp problem statements, explicit constraints, and measurable design criteria. Identify what must be obvious in the first 5 seconds.

→ Applied in Doppelgänger Alarm Fatigue
Problem Framing Information Hierarchy Success Metrics
03 Diverge

Explore

Explore multiple divergent interaction flows and low-fidelity wireframes. Compare architectural alternatives before converging on the model with the lowest cognitive friction.

→ Applied in DevEx Wireframe Trade-offs
User Flows Low-Fi Wireframes Trade-Off Analysis
04 Build

Prototype

Bring ideas into reality with living high-fidelity UI and code prototypes. Test realistic edge cases, responsive adaptations, and micro-interactions so the solution can be felt.

→ Applied in Provenance 3-Tier Prototype
Interactive Prototyping Component Design Code Feasibility
05 Learn

Validate

Put prototypes in front of real users. Watch where people hesitate, listen to their immediate confusion, and treat unexpected behaviors as the most valuable feedback.

→ Applied in HackOasis V3 (2nd of 75+)
Usability Testing Task Success Rate Qualitative Notes
06 Refine

Iterate

Refine visual polish, accessibility (contrast, keyboard focus, screen readers), and state handling based on evidence. Prepare systematic handoffs for engineering execution.

→ Applied in Provenance 3-Tier IA Refinement
Accessibility Tuning Micro-Interactions Design Handoff

Rethinking YouTube Video Discovery 📺

An independent exploration of interaction design and intentional content discovery

Modern video platforms often lock viewers into repetitive recommendation bubbles or endless passive feeds. This concept explores how lightweight "Intent Modes" give viewers agency over depth and variety without disrupting the effortless watching experience.

Core UX Challenge

Balancing algorithmic serendipity with user-directed discovery modes.

Deliverables

Interactive discovery feed prototype, wireframes, and design rationale.

Doppelgänger 🕵️

Communicating web privacy risk without triggering alarm fatigue

A browser extension designed to audit live web interactions. Most security tools overload non-technical users with cryptographic terms; Doppelgänger introduces plain-language risk tiers, visible non-color cues, and a 1-click mitigation path.

Core UX Challenge

Transforming complex tracker metadata into a clear 3-second status verdict.

Deliverables

Functional extension, interaction flows, and comprehensive research report.

CIOrchestration 🚦

Autonomous CI/CD failure root-cause analysis and automated pull requests

When pipelines break, engineers drown in thousands of raw log lines. CIOrchestration deploys a 3-agent diagnosis system that presents the root cause first, shows a collapsible reasoning timeline with confidence cues, and offers a 1-click pull request resolution.

Core UX Challenge

Communicating AI confidence and evidence so tired developers trust the verdict in seconds.

Achievement

2nd Place among 75+ teams at HackOasis V3 (Python, LLMs, React).

Provenance 📦

Supply chain transparency platform making product authenticity verifiable

Global supply chains are opaque and difficult to audit. Provenance restructures complex multi-party custody records into an intuitive, scannable timeline where inspectors and buyers can verify provenance, tamper seals, and ethical certs in seconds.

Core UX Challenge

Designing an information architecture that makes cryptographic ledger records easy to scan.

Deliverables

Full-stack verification application, dashboard UI, and custody timeline.
